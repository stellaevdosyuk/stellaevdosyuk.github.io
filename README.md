# stellaevdosyuk.github.io

Privacy Policy, Terms of Use and Support pages shared by all our apps, served by GitHub Pages.

| Page    | URL                                         |
|---------|---------------------------------------------|
| Privacy | https://stellaevdosyuk.github.io/privacy/   |
| Terms   | https://stellaevdosyuk.github.io/terms/     |
| Support | https://stellaevdosyuk.github.io/support/   |

Plain HTML and CSS, no build step: edit a page and push to `main`, and it is live in about a minute.

When the text of a policy changes, also update its "Effective" date in the page hero.

## Apps

The home page lists our released apps under "Our apps". To add one, copy an `<li class="app">` block in `index.html`, put a 256×256 PNG icon in `assets/apps/`, and link to `https://apps.apple.com/app/id<Apple ID>`.
